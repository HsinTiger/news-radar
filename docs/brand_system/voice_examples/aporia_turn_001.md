# Aporia Turn Anchor Sample 001 · Hsin coda on 主角會死配角會富 (2026-05-15)

## 原文（preserve, 0 編輯）

```
▉ 我自己呢？

我算是個主角感很重的人，總覺得一生一定要幹點大事才罷休的性格，
喜歡風險、喜歡豐功為業、喜歡感受到自己活著，不段追求生命中的熱血感，
近來遇到下風期，不經讓我思考：萬一我只是個配角呢？如果腦袋構想的畫面不成怎麼辦？當個配角會怎樣？我接受的了那樣的自己嗎？沒沒無聞、當個nobody。

真實的人生不像影劇一般精彩，好像天天都是高潮迭起的。雖然我覺得我已經盡力活得像影劇人物了，但現實總不免有需要你沉澱下來的階段。

也許吧，配角也是能過的很好的，有一種柔韌度，是我們都擁有可以在主角與配角持續切換的彈性，允許自己偶爾當個配角，而且不是那種逼不得已配合的情況，是真實的祝福別人，心甘情願。

也許吧，有一天我會把也許拿掉，或是更堅定的維持我的主角步伐。
```

## Pattern 拆解（給未來 PM agent 寫 Aporia 時參考）

### 1. 開場 self-implicating: 直接承認自己屬於本文批評的那類人

> 「我算是個主角感很重的人」

直接、不掩飾、不用 hedging。讀者讀到這句立刻信任作者「他在跟我一起想、不是站在上面教我」。

### 2. 中段「但是」: 用具體場景觸發 self-doubt

> 「近來遇到下風期、不經讓我思考：萬一我只是個配角呢？」

「下風期」是具體 anchor、不是抽象「人生有時候會 X」。讀者知道作者真的在某個現實處境裡寫這段。

### 3. 接受不確定: 「也許吧」reframe 不下結論

> 「也許吧、配角也是能過的很好的」
> 「也許吧、有一天我會把也許拿掉」

兩個「也許吧」串在一起。第一個 acknowledge 對立可能、第二個 reframe 不確定本身是個過程。

### 4. 不收 punchline: 用 self-修正可能性結尾

> 「或是更堅定的維持我的主角步伐」

最後一句**允許自己留在原本立場**。這是高階 Aporia——不是「我覺悟了我以前錯了」、是「我接受答案還沒定下來」。

---

## Anti-pattern · 不要寫成這樣

❌ 假 Aporia（最常見的失敗）：

> 「寫完這篇我也在反思自己。我以為自己是主角、後來發現主角會死。所以從今天起、我選擇當配角、認真累積複利、不在乎被看見。」

問題：
- self-doubt 是裝的、最後立刻 resolve
- 沒有矛盾保留、答案太乾淨
- 結尾下結論「從今天起 X」是 Hsin 5/14 禁的 prescriptive ending

真 Aporia 必須**保留懸而未決**、不能假裝「我已經想通了」。
