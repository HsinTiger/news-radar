# 框架：週期判讀與資金終點

> 蒸餾自 `notes/45`（AI 會毀掉經濟嗎 — 資金流向四終點）與
> `notes/35`（3.5 兆私募信貸贖回風暴為何不是下一個 2008）。
> 主要用途：在多空敘事極端化時，判斷這是結構性轉折還是週期波動。

## 這個框架回答什麼

當市場出現「這次不一樣，要崩了」或「這次不一樣，要噴了」的直線型敘事時，
怎麼避免被敘事帶走？

核心命題（`notes/45` 原文金句）：

> 「經濟是一個循環，不是一條直線」
> 「誰拿到錢，比總共有多少錢更重要」

**直線型末日論的通病**：把複雜系統簡化成單一因果鏈，忽略多重力量互相抗衡。
崩潰劇本通常只在**所有制衡機制同時失效**的極端條件下才成立。

## 動作一：把敘事拆成資金的四個終點

任何「某某效率提升／成本下降」的敘事，錢不會消失，只會流向四個終點之一：

| 終點 | 內容 | 觀測訊號 |
|---|---|---|
| **A 保留** | 企業把省下的錢變成利潤留著 | 毛利率擴張、庫存現金堆積、回購 |
| **B 傳導** | 競爭迫使降價，讓利給下游 | 售價下滑、單位經濟惡化、價格戰 |
| **C 再投資** | 投入互補創新，長期創造新需求 | 資本支出、新品類、新職缺出現 |
| **D 重分配** | 政府稅收與政策介入 | 稅制變動、補貼、監管 |

**崩潰只在極端組合下成立**：A 獨佔 + B 不存在 + C 太慢 + D 被政治僵局卡死。
四個同時失效才是災難；只要有一兩個在運作，就是週期而非轉折。

分析時必須**四個終點逐一評估**，不能只講一個就下結論。
只講 A（企業囤利潤）就宣告末日，正是這個框架要打破的推論。

## 動作二：分辨「局部失效」與「系統性崩潰」

`notes/35` 的私募信貸案例給的是判準：規模嚇人（3.5 兆美元）不等於系統性風險。
要問的是**傳染路徑**，不是絕對規模：

- 損失是**留在持有人身上**，還是會透過槓桿與擔保品鏈條放大？
- 資金是**鎖定期資本**（不能贖回 → 不會擠兌），還是可隨時贖回的短錢？
- 對手方是分散的，還是集中在少數節點？

**沒有傳染路徑的大數字 = 新聞標題，不是系統性風險。**
有傳染路徑的小數字才危險。

## 動作三：檢查你的觀測指標有沒有失效

框架本身也會過期。舊週期指標在結構改變後可能不再有預測力
（例：市場結構因機構化、ETF 化而改變後，過去的週期頂底指標可能失準）。

規則：**指標連續失效兩次以上，就必須降權或除役，不能因為「歷史上很準」而
繼續採用。** 在分析中要明確標示某指標已進入觀察期或已除役，
而不是悄悄不提。

## 判定輸出

| 判定 | 條件 |
|---|---|
| **週期波動** | 四終點中至少兩個在運作；無明確傳染路徑 |
| **結構轉折** | 四終點同時受阻，或出現新的傳染路徑 |
| **判定不能** | 關鍵資料缺失 —— 明說缺什麼，不要用推測補 |

「判定不能」是合法且必要的輸出。這套系統的價值在於**不假裝知道**。

## 什麼情況下這個框架會失效

- **AGI 情境**：若認知能力全面超越人類，終點 C 所依賴的「人類總能找到新工作」
  的歷史經驗假設會整個失效。此時框架的樂觀偏誤最大。
- **溫水煮青蛙**：四個終點都「有在動但力道不足」時，框架會誤判為健康，
  而系統其實正緩慢逼近臨界點。對策是看**趨勢的二階導數**，不只看有無運作。

## 對接 BTC repo 的用法

- 每次要更新「行情觀點」而非「行情數據」時，跑一次這個框架。
- 輸出必須包含**反面**：這個判定在什麼條件下會被推翻，以及那個條件的
  觀測指標是什麼。沒有可證偽條件的觀點不予採用。
