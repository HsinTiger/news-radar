## §C0 鐵律（先讀這條，違反就重來）

1. **數字只准來自「財報事實」區塊（yfinance）**——prompt 裡會給一段標「📊 財報事實」的數字。所有營收、利潤率、市值、估值、回落幅度，**一律引用那段，逐字對齊**。記憶中的舊數字、網搜到的數字一律不准用來取代它；那段沒有的就**明說「資料未揭露」**，絕不瞎掰、絕不四捨五入到「差不多」。
2. **長度 3000-4500 字**——不是曼報四部曲的長度。寫不完就砍枝節，別灌水。
3. **這是分析、不是吹捧也不是看衰**——多空都要 steelman，最後**下一個明確評等與判斷**（接 §14 敢下判斷）。
4. **可遷移**——結尾一定要把這間公司的故事抽象成一條別的公司也適用的法則（曼報最值錢的部分）。

## §C1 文章結構（六段，單篇）

**開場（≤180 字）**：§6/§6.1 反共識標題 + 開篇兩句就**下一句話結論評等**。
- 評等用一條光譜詞：`優異 / 中上 / 中等 / 中下 / 危險`，後面接一句定性（例：「中上：從『定義品類的唯一龍頭』降級為『得肉搏防守的成熟龍頭』」）。
- 一句話點出「市場現在怎麼看它，而你要修正哪個共識」。

**§A 商業模式地圖**：
- 賣什麼（產品/收入分層，哪層是入口、哪層是利潤核心）。
- 改變了什麼（它把產業的什麼工作流／價值分配重組了）。
- 護城河與飛輪（自我強化循環；用一兩句講清楚「為什麼後進者短期追不上」或「為什麼其實追得上」）。

**§B 財務解析**（**只用財報事實區塊的數字**）：
- 營收成長軌跡 + CAGR + 利潤率趨勢，**一句話定調**（加速 / 高原 / 衰退）。
- 區分「一次性順風」與「結構性能力」（例：疫情遞延、匯率、認列方式 vs 真實滲透）。
- 抓 1-2 個最關鍵的財務張力（毛利率 vs 營益率背離、ROE 高但再投資報酬下滑、估值 vs 成長落差…）。

**§C 競爭與風險**：
- 競爭格局正在怎麼變（誰用什麼方式切入、為什麼現在切得進來）。
- 2-3 個結構性風險（市場天花板、通路鬆動、護城河商品化、單一市場/客戶集中…），各一句講清機制。

**§D 未來情境分析**（這段是重點，曼報最強的地方）：
- **三情境**：多頭 / 基準 / 空頭——各給「要成立需要什麼條件」+「對應的估值含義」。
- **高勝算 vs 高風險拆解**：哪些是「執行力」範疇（滲透、降本，確定性高）、哪些是「市場/競爭」變數（確定性低）。
- **關鍵監測指標**：列 2-3 個「比 GAAP 營收更早告訴你轉型成不成」的領先指標（如開票 billings、遞延收入、活躍客戶數、單位通路產出、特定產品線出貨）。

**結尾·可遷移反思（≤200 字）**：把這間公司的故事抽象成一條法則，並丟一個給讀者的開放思考題（接 §7 開放結尾、§14 照妖鏡）。
- 例：「品類開創者把手工藝數位化、無意間替後進者鋪路」是一種結構性宿命——還有哪些公司正以全面數位化為榮、卻不知在替對手開路？
