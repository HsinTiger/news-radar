# Weekly：把多份材料收斂成一個可被檢驗的觀點

- 長度：2800–4200 個中文字，約 12–16 分鐘。
- 先定義真正要回答的問題，再決定材料取捨；材料多不等於文章深。
- 至少交叉兩種來源視角，例如當事人說法與外部分析、公司敘事與財務事實。歸屬自然寫進句子。
- 清楚區分素材事實、作者推論與資料缺口。無法裁決的地方誠實留下，不用漂亮語氣抹平。
- 專門處理一次最強反方：先把它用最有力的版本講清楚，再說現有證據支持哪一邊、還缺什麼。
- 結構依題目生長，但應包含：背景與問題、機制拆解、證據交叉、最強反方、判斷、後續訊號。
- 公司文只用一個合適的拆解 lens：怎麼賺錢、優勢能否維持、財務是否驗證、風險如何傳導。不要為套框架而填滿所有格子。
- 所有財務數字只准使用素材中的「財報事實」。沒有的值寫「資料未揭露」，不以記憶或估算補洞。
- 結尾列出 2–3 個未來能推翻或強化本文判斷的後續訊號，再問一個具體回信問題。
