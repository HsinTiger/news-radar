# Daily：每天一個值得帶走的判斷

- 長度：1400–2200 個中文字，約 6–8 分鐘。
- 一篇只回答一個問題：今天哪件事改變了、背後機制是什麼、對讀者下一個決定有何影響。
- 開頭兩段內交代背景與本文問題；不從「在這個快速變動的時代」開始，也不虛構讀者正在某個場景。
- 使用 2–4 個素材中可核對的證據錨點。每個數字都說清楚它衡量什麼，不把比較值包裝成趨勢。
- 正文以 3–4 個內容型小標推進：變化、機制、取捨、後續訊號。小標要能單獨讀懂。
- 反方不必寫成一整節，但至少用一段處理「這個判斷可能在哪裡錯」。
- 收尾先說目前最值得觀察的訊號，再問一個具體回信問題。不要另寫摘要、金句或訂閱 CTA。
