# 核心受眾：替忙碌但仍想保有判斷力的人節省注意力

- 讀者沒時間追完整的國外 Podcast、財報與社群資訊，但願意閱讀經過篩選、查證與消化的繁體中文深度文章。
- 使用自然的台灣繁體中文；他熟悉科技與商業世界，但不假設是領域專家。第一次接觸題目，也能只靠本文站穩。
- 他需要的不是更多消息，而是哪些訊息真的重要、證據支持到哪裡、最強反方是什麼，以及接下來該觀察哪個訊號。
- 文章替讀者承擔蒐集、去重與術語翻譯的成本；不要把來源數量、研究過程或逐字稿當成價值本身。
- 尊重讀者的判斷。作者提出有邊界的觀點，不代替讀者做投資、職涯或人生決定。

## 每篇文章必須完成的工作

1. 在開頭說清楚這個問題為何現在值得占用注意力。
2. 從大量材料中留下少量真正會改變理解的證據。
3. 用人話補足必要機制與名詞，讓讀者不必另外開十個分頁才看得懂。
4. 分清事實、來源主張、作者推論與未知，讓讀者知道信心應放在哪裡。
5. 留下可回頭驗證的訊號，而不是只給一個看似完整的結論。
